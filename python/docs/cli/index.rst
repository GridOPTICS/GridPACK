====================================================
GridPACK Command-Line Interface
====================================================

*Release 3.5*

**GridPACK Dev Team**

.. rubric:: About This Manual

This manual describes the GridPACK unified command-line interface (CLI),
a Python-based tool that provides a single entry point for running
GridPACK power system analysis applications. The CLI is built on top
of the GridPACK Python bindings and is designed for both interactive
use and integration into automated workflows.

For the underlying Python API reference, see the companion document
*GridPACK Python Interface, Release 3.4*.
